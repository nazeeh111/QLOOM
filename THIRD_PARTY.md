# Dependencies, prior work and media

QLOOM is an original integration and implementation, with a bounded research claim. The algorithms build on established graph placement, shortest-path routing, commutation and ensemble regression ideas. Learning compilation and using graph representations are established research areas. See [related work](docs/research-foundations.md) for the requested papers and newer methods.

No dependency code is vendored into the compiler. Installed transitive dependencies keep their licenses. Model labels and shipped weights are generated by QLOOM's reproducible native compiler evaluations. The JSON model contains tree parameters, not serialized executable Python.

Brand, circuit figures, architecture diagrams, screenshots and launch visuals are generated for this project. System font stacks do not redistribute font files. The launch folder contains its own media provenance and any rendering-runtime attribution. No paper figures or vendor logos are copied. PaperVizAgent was investigated; the delivered diagrams use editable SVG sources with local rendering instead of paid model APIs.
