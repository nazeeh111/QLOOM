# QLOOM Studio visual system

QLOOM is a computational instrument, with the warmth of a paper laboratory notebook. Circuit wires and routed paths provide its identity. The woven mark is original SVG, editable in `src/qloom/web/assets/favicon.svg`.

- Canvas: warm gray `#f3f2ec`; surfaces ivory `#fffefa`; text ink `#203239`.
- Quantum paths: restrained blue `#315d7a`; active transformations and frontier: amber `#bc7e35`.
- Success: forest `#387455`; failure: dark rust `#9b3e30`. Every state also uses a text label.
- Typography: locally available system sans; system monospace for source, measurements and mappings. No external fonts or CDNs.
- Persistent configuration rail, compact experiment summary, then circuit evidence. Physical mappings, search and compiler comparisons follow in readable groups.
- Circuit SVG diagrams derive from real operation lists. The processor graph derives from device edges. Recorded history is replayed without fabricating new steps. Charts derive from report measurements.
- The compile request uses indeterminate pending feedback. Actual elapsed evaluation times appear after completion. Recorded experiments carry a visible label.
- All exports retain reproducibility metadata, including mappings and global phase. Noisy output comparisons are explicitly distinct from logical equivalence.
- Focus rings, keyboard-operable graph nodes and chart points, labels, responsive stacking, and reduced-motion behavior are included.
