# Studio API v1
Python server: `qloom studio` on 127.0.0.1:8765. Static frontend in `src/qloom/web/` (index.html, app.js, style.css); no CDN dependencies.
- GET /api/examples -> [{id,name,description,qasm}]
- GET /api/devices -> [{name,n_qubits,edges:[[a,b]],single_error,two_error,readout_error,single_duration_ns,two_duration_ns,noise_source}]
- POST /api/compile JSON {qasm:string,device:string,budget:integer 1..24,seed:integer,strategy:'learned'|'random'|'heuristic'} -> report
- GET /api/demo -> stored genuine demo report (same schema)
- GET /api/benchmarks -> stored benchmark summary JSON
Report: {schema_version,seed,strategy,budget,device,input:{name,n_qubits,operations:[{gate,qubits,params}],measurements:[[logical,classical]],global_phase,qasm},candidates:[{id,config:{layout,routing,lookahead,rewrite},metrics:{two_qubit_gates,depth,duration_ns,estimated_success,objective,compile_time_s},verification:{passed,method,max_error,global_phase_error,randomized_max_error,trials},initial_mapping:[physical per logical],final_mapping:[physical per logical],operations:[{gate,qubits,params}],history:[{step,kind,label,qubits,mapping}],qasm,global_phase,model_prediction,elapsed_s}],best_id,pareto_ids,baselines:[same candidate schema plus name,status,reason?],noise:{method,assumptions,ideal_probabilities,optimized_probabilities,input_probabilities,optimized_fidelity,input_fidelity,shots?},model:{name,training_rows,training_circuits,features,sha256},elapsed_s,export_note}
Candidates and baselines equivalence must be checked and physical edges satisfied. SVG circuit, connectivity and charts can be derived entirely from report. Input circuits <=8 qubits, unitary+terminal measurements, u/cx simulated native set. Demo stored server-side and API always performs genuine compile. QASM2 cannot represent global phase; export bundle reports `global_phase` and mappings explicitly. UI downloads JSON report, individual .qasm and metadata sidecars. Errors use FastAPI {detail:string}. Compilation synchronous API; frontend displays honest indeterminate progress while waiting, then measured per-candidate elapsed_s history, never fake live progress. Routing history is recorded actual swaps and can be replayed with a slider.
